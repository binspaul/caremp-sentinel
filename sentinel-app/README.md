# 📱 careMP Sentinel — Patient Health Companion

> **Mobile & Tablet Web Application for Personal Healthspan, Organ Digital Twin & Gemini AI Companion**  
> *Part of careMP Sentinel | Build 2036 Health, Longevity & Biotechnology*

## Overview
The **careMP Sentinel Patient App** is the resident- and patient-facing interface for longevity care:
- **Interactive Anatomical Twin (`humanBodyIllustration.tsx`)**: Real-time visual feedback on brain, cardiac, pulmonary, and metabolic biomarkers.
- **Gemini Health Companion (`aiHealthCompanion.tsx`)**: Empathetic conversational AI health coach.
- **Continuous Biometric Telemetry**: Live vital signs, HRV recovery scores, and sleep dipping metrics.
- **Multi-Device Responsive**: Built with responsive layouts for iPhone, iPad, and desktop viewports.

## Running Locally
```bash
npm install
npm run dev
# Runs on http://localhost:5174
```
